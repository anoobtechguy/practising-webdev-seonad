# Portfolio Website for Google Indexing Practice & Ad Testing

This project is a personal portfolio website built to practice website indexing, SEO basics, and ad-related setup while showcasing an anime video editor and thumbnail designer portfolio.

The site is a lightweight static website designed for learning how search engines crawl and index content, how to configure metadata, and how to test advertising/marketing flows on a live website.

## Project Purpose

- Practice Google indexing and Search Console setup
- Test website visibility and crawler behavior
- Learn how to publish SEO-friendly pages
- Explore ad placement and marketing setup for a website
- Present a portfolio for freelance video editing and thumbnail design services

## Project Overview

This website includes:

- A landing page with portfolio branding
- Hero section and service highlights
- Work samples and client testimonials
- Contact form section
- SEO tags and site metadata
- robots.txt and sitemap.xml for indexing practice
- Responsive UI for desktop and mobile devices

## Local Setup

To run the website locally:

1. Open the project folder.
2. Start a local server in the project directory.
3. Open the site in your browser.

Example using Python:

```bash
cd "C:\Users\hp victus\OneDrive\Desktop\krish"
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Google Indexing Practice

This project is useful for learning the following SEO/indexing tasks:

- Adding a title, description, and keywords
- Publishing a sitemap.xml file
- Configuring robots.txt
- Making pages crawlable and indexable
- Submitting the website to Google Search Console
- Checking indexing status and search appearance

### Suggested workflow

1. Upload the website to a live hosting service.
2. Add the domain to Google Search Console.
3. Validate ownership using one of the recommended methods.
4. Submit the sitemap.
5. Check whether pages are indexed.
6. Review crawl, coverage, and mobile usability reports.
